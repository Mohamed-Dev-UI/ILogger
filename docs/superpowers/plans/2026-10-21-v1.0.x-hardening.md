# v1.0.x Hardening (G-06, G-07, G-08, G-12) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the shipped v1.0.0 claims true: file rotation never corrupts or throws, cancelled coroutines are not logged as failures, the KSP processor works across rounds with incremental-correct dependencies, and the untested built-in sinks/context/integrations have tests.

**Architecture:** Four independent workstreams, executed in order G-06 → G-07 → G-08 → G-12. G-06 touches only `ilogger-core` sink code; G-07 adds one annotation parameter plus a second catch branch in generated code; G-08 restructures processor state; G-12 adds tests (and only fixes bugs those tests expose). Every task ends with a green module test run and a commit.

**Tech Stack:** Kotlin 2.2.10/JVM 17, kotlinx-coroutines 1.11.0, JUnit 4, KSP 2.3.12, KotlinPoet 2.2.0, Ktor server test host (already a test dependency).

**Spec:** `GOALS.md` G-06, G-07, G-08, G-12; master plan `2026-10-21-full-roadmap.md`.

**Status (2026-10-21):** Tasks 1–7 implemented; `./gradlew test` green. Commit steps remain unchecked on purpose — no commits are made until the user asks for them.

## Global Constraints

- `TextFileSink` stays a `DirectLogSink`; `writeDirect` is synchronous and documented as blocking.
- No new runtime dependency in `ilogger-core` (fsync/gzip use `java.nio`/`java.util.zip`).
- Generated wrappers must not reference `kotlinx-coroutines` types; use `kotlin.coroutines.cancellation.CancellationException`.
- Original exceptions are rethrown by identity and never replaced by a logging failure.
- Existing public constructors/annotation defaults remain source-compatible.
- Every bug fix lands with the failing test first.
